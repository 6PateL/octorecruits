# Octo Recruits (Forge 1.20.1)

Рекрути, які носять **Tentacle Rig** з моду Create: Octo Arms (`tentaworks`) у слоті нагрудника, лазять по стінах як павуки.
Кнопки використання немає: риг працює, поки він одягнений.

## Як це працює
- Одна ціль `OctoClimbGoal` без прапорців, тому вона не заважає рекрутам битись, слідувати чи тримати позицію.
- Перевіряється кілька полів рекрута (чи тисне він у стіну під час руху), ніяких пошуків по світу чи сканування блоків.
- Якщо в рекрута є ворог вище, до якого немає звичайного шляху (дах, скеля), він іде на нього напряму, впирається в стіну й лізе.
- Падіння під час лазіння не шкодить.

## Конфіг (`octorecruits-common.toml`)
`enabled`, `climbSpeed` (0.2 як у павука), `chaseRange` (24, 0 = вимкнено), `useAir` (false) та `airPerSecond`.
`useAir`: лазіння витрачає повітря ригу (це бектанк), списується раз на секунду.

## Збірка
`gradle build` (jar з'явиться в `build/libs`). Залежності (Create, Recruits) лежать у `libs/`.
